# susrota.com

Landing page for [Srota](https://susrota.com) — local-first, on-device voice transcription for Mac.

- On-device inference, no audio leaves your machine
- Hinglish (Hindi + English) transcription
- Apple Silicon optimized

## Development

Plain HTML/CSS/JS — no build step required.

```
open index.html
```

## Deploy

Hosted on Netlify at [susrota.com](https://susrota.com).
